# greatliv - LiverBo

Dit project bevat nu **Neon Stack**: een moderne browsergame (2026-stijl) geïnspireerd op Tetris.

## Starten
Open `index.html` direct in je browser, of gebruik een lokale webserver:

```bash
python3 -m http.server 4173
```

Ga daarna naar `http://localhost:4173`.

## Features
- 7-bag randomizer
- Hold-blok (`C`)
- Next queue (5 previews)
- Ghost piece
- Score, level en lines
- Pauze (`P`) en restart knop
- Neon UI met responsive layout
